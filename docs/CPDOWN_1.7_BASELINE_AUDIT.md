# cpdown 1.7 — базовый аудит перед разработкой 1.8

Дата фиксации: 2026-07-21

Базовая ветка: `main`

Базовый коммит: `5dbfbdfcf5021947af40709b0e560f6d1c186d4a`

Рабочая ветка: `feature/cpdown-1.8`

## 1. Подтверждённое состояние репозитория

Ветка `main` содержит рабочую устанавливаемую сборку cpdown 1.7, но не содержит полного воспроизводимого исходного WXT-проекта.

Не найдены в корне:

- `package.json`;
- файл блокировки зависимостей;
- `wxt.config.*`;
- `tsconfig.json`;
- исходные точки входа WXT;
- исходные React-компоненты;
- исходная модульная версия основного фонового обработчика;
- тестовая конфигурация.

README при этом указывает команды `npm install`, `npm run dev` и `npm run build`, которые нельзя выполнить на текущем содержимом `main`.

## 2. Текущая архитектура сборки

- Manifest V3.
- Service Worker: `background-wrapper.js`.
- `background-wrapper.js` загружает `background.js` и `background-xcom.js` через `importScripts`.
- `background.js` является крупным собранным и минифицированным файлом.
- `options.html` подключает хешированные готовые ресурсы.
- `content-scripts/content.js` пуст, но постоянно загружается на всех страницах.
- `content-scripts/save-selection.js` также загружается на всех страницах.
- В манифесте присутствует `<all_urls>`.
- Ключ манифеста сохранён и должен остаться неизменным для сохранения идентификатора расширения.

## 3. YouTube — подтверждённые проблемы

- Текущий извлекатель безусловно использует `captionTracks[0]`.
- Выбранный пользователем язык проигрывателя не учитывается.
- Существующая проверка соответствия `videoId` URL и `playerResponse` должна быть сохранена.
- Очистка SRT удаляет только номера, временные метки и пустые строки.
- Перекрытия автоматических субтитров не устраняются.
- HTML-сущности отдельно не нормализуются.
- Markdown содержит только название и текст.
- Канал, ссылка, язык и тип субтитров не добавляются.
- Оценка токенов использует только `длина / 4`.
- `youtube-main-world.js` содержит рабочий перехват параметра `pot`, но не возвращает сведения о выбранной дорожке.
- В рабочей сборке присутствует лишний вывод в консоль.

## 4. X — подтверждённые проблемы

- Независимо обходятся `tweetText`, `div[lang]`, `article` и `[role="article"]`.
- Возможны дубли и повторное извлечение вложенного содержимого.
- Результаты сортируются по длине текста, а не по порядку DOM.
- Присутствует жёсткий предел `slice(0, 10)`.
- Автор определяется упрощённо по URL страницы.
- Не извлекаются структурированные дата, постоянная ссылка, цитируемая публикация и медиа.
- Уведомление вставляется непосредственно в DOM страницы без Shadow DOM.
- Уведомление автоматически исчезает через 4,5 секунды.
- Интерфейс X остаётся англоязычным.
- После обработки выполняется автоматическое копирование, но нет полноценного действия сохранения `.md`.

## 5. Вывод по восстановлению исходников

`background.js` нельзя использовать как основной редактируемый исходник версии 1.8.

Правильный порядок работ:

1. Сохранить сборку 1.7 как эталон поведения.
2. Проверить историю Git, ветки и теги на наличие полного WXT-проекта.
3. Если исходники не найдены, создать воспроизводимый WXT + TypeScript проект.
4. Перенести существующую рабочую логику без изменения поведения.
5. Добиться регрессионной совместимости с 1.7.
6. Только после этого внедрять требования 1.8.

## 6. Приоритеты следующего этапа

1. Создать каркас WXT + TypeScript.
2. Восстановить манифест с сохранением ключа расширения и команды `copy-as-markdown`.
3. Перенести текущие сценарии статьи, выделения, YouTube и X.
4. Добавить тестовые фикстуры для зафиксированного поведения 1.7.
5. Настроить воспроизводимую сборку.
6. Не добавлять новые функции 1.8 до достижения базовой совместимости.

## 7. Ограничения текущего аудита

GitHub-коннектор предоставляет содержимое файлов и коммиты, но неполно отображает дерево и историю проекта. Локальное клонирование в текущей среде не удалось из-за отсутствия сетевого разрешения DNS. Поэтому поиск утраченных исходников по полной истории должен быть дополнительно выполнен средой разработки с обычным доступом к GitHub.
