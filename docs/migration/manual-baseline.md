# Ручные тесты — cpdown v1.7 до миграции на WXT

Цель документа — зафиксировать набор сценариев, которые человек выполняет вручную в Chrome
для подтверждения, что текущая версия расширения работает корректно **до** начала миграции.
Результаты станут отправной точкой для сравнения после миграции.

## Инструкция

1. Установите cpdown v1.7 из папки `dist/` (или из текущей ветки) в Chrome: **chrome://extensions → Загрузить распакованное расширение**.
2. Выполните каждый сценарий из таблицы ниже.
3. Заполните колонки **«Факт»**, **«Дата»** и **«Снимок Markdown»** после выполнения каждого сценария.
4. В колонке «Снимок Markdown» вставьте содержимое скопированного/сохранённого Markdown-файла **без личных данных** (замените usernames, email и т. п. на `{REDACTED}`).
5. Если результат не совпадает с ожидаемым — пометьте это в колонке «Факт» и добавьте скриншот ошибки.

> **Важно:** Для сценариев B-03 – B-05 и B-09 нужен аккаунт X.com / Twitter.
> Для сценариев B-06 – B-09 нужно стабильное соединение для загрузки субтитров YouTube.

## Таблица сценариев

| Код | Ссылка / тип страницы | Действие | Ожидаемый результат | Факт | Дата | Снимок Markdown без личных данных |
|-----|------------------------|----------|---------------------|------|------|-----------------------------------|
| **B-01** | Любая статья (например, Wikipedia) | Нажать иконку cpdown или `Ctrl+Shift+T` → Copy | Чистый Markdown в буфере обмена | | | |
| **B-02** | Та же страница | Выделить абзац → Copy → появляется кнопка «Sel» → Save .md | Только выделенный текст сохраняется | | | |
| **B-03** | Открытый пост на x.com / twitter.com | Правый клик → «Copy X.com Markdown» | Markdown скопирован; toast показывает 1+ блоков | | | |
| **B-04** | Тред из 3+ твитов на x.com / twitter.com | Правый клик → «Copy X.com Markdown» | Порядок твитов совпадает с отображением на странице | | | |
| **B-05** | Пост на x.com / twitter.com с блоками кода | Правый клик → «Copy X.com Markdown» | Отступы и положение кода сохранены | | | |
| **B-06** | Видео на YouTube с ручными субтитрами | Нажать иконку cpdown | Транскрипт получен; toast показывает Copy / Save | | | |
| **B-07** | Видео на YouTube только с автоматическими субтитрами (ASR) | Нажать иконку cpdown | Расшифровка получена (ASR-качество) | | | |
| **B-08** | Видео на YouTube без субтитров | Нажать иконку cpdown | Понятная ошибка (не «undefined» и не сырая exception) | | | |
| **B-09** | Видео на YouTube с выключенными CC | Запомнить, что CC = OFF → извлечь транскрипт → проверить CC | CC остаются выключены после извлечения | | | |
| **B-10** | Любая страница | Перезагрузить расширение → попробовать извлечь | Появляется сообщение «refresh tab» или работает сразу | | | |
