# cpdown

> 📄 Копируй веб-страницы, субтитры YouTube и контент X.com в чистый Markdown, готовый для LLM.

**cpdown** — лёгкое расширение для браузера, чтобы сохранять полезный контент без лишнего шума: статьи, выделенный текст, транскрипты YouTube и видимые посты, треды и статьи X.com / Twitter.

---

## ✨ Возможности

- 🧭 **Кнопка на панели** — нажми на иконку расширения или `Ctrl+Shift+T`
- 🎬 **Субтитры YouTube** — скопируй транскрипт текущего видео в Markdown
- 🖱️ **Контекстное меню YouTube** — кликни правой кнопкой по ссылке YouTube → **Copy subtitles**
- ✕ **Контекстное меню X.com / Twitter** — кликни правой кнопкой на странице X.com → **Copy X.com Markdown**
- 🧼 **Readability / Defuddle** — извлеки чистый текст статьи с обычной страницы
- 📋 **Копирование в буфер** — Markdown сразу готов к вставке
- 💾 **Скачать как `.md`** — сохрани результат в файл (там, где это поддерживает сценарий)
- 🔢 **Счётчик токенов** — в тосте транскрипта отображается примерное количество токенов
- ✅ **Единый дизайн тостов** — сообщения с кнопки и из контекстного меню выглядят одинаково

## 🚀 Использование

### Скопировать текущую страницу

1. Открой любую обычную страницу
2. Нажми иконку **cpdown** на панели или `Ctrl+Shift+T`
3. Используй кнопки в тосте:
   - **Copy** — скопировать Markdown в буфер обмена
   - **Save .md** — сохранить Markdown в файл

### Скопировать контент X.com / Twitter

1. Открой пост, тред или статью на X.com / Twitter
2. Дождись, пока контент отобразится на странице
3. Кликни правой кнопкой в любом месте страницы
4. Выбери **Copy X.com Markdown**
5. cpdown сразу скопирует Markdown в буфер обмена и покажет тост с количеством извлечённых блоков

Этот сценарий читает уже открытую в браузере страницу. Он **не** использует официальный API X и **не** требует платных внешних API.

Текущее ограничение: в статьях X.com с большим количеством кода отступы могут сохраняться неидеально. В v1.6 выбран самый читаемый вариант из альфа-тестов, а улучшение точности блоков кода отложено на следующие версии.

### Скопировать субтитры с текущего видео YouTube

1. Открой видео на YouTube
2. Нажми иконку **cpdown** на панели
3. Расширение извлекает транскрипт через скрытую вкладку — так результат стабильнее
4. В правом верхнем углу появляется тост с количеством токенов и кнопками **Copy** / **Save .md**

### Скопировать субтитры со ссылки YouTube

1. Кликни правой кнопкой по любой ссылке YouTube (`youtube.com` или `youtu.be`)
2. Выбери **Copy subtitles**
3. Расширение открывает видео в скрытой вкладке, извлекает транскрипт, закрывает вкладку и показывает результат на исходной странице
4. Если что-то пошло не так, появится красный тост с текстом ошибки и кнопкой **Copy log** — она копирует журнал шагов для отчёта об ошибке

## 🔐 Разрешения

- `activeTab` — доступ к текущей вкладке
- `clipboardWrite` — копирование Markdown в буфер обмена
- `contextMenus` — пункты контекстного меню для YouTube и X.com
- `scripting` — внедрение скриптов извлечения
- `storage` — хранение настроек пользователя
- `<all_urls>` — извлечение со страниц, уже открытых в браузере

### v1.8.1

- **Исправлено:** Правый клик → **Copy subtitles** копировал только название видео без текста
